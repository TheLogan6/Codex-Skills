# 已有项目回读

## 目标

从有效的 `.cvpr/` 当前快照和账本恢复长期研究上下文，讨论项目当前进度并提出下一项原子任务。

## 执行顺序

1. 运行 `validate_cvpr_state.py`。
2. 校验通过后读取七个基础状态文件，并枚举存在的 `start.yaml`、`goal.yaml`、`plan.yaml`、`result.yaml`、`paper.yaml`。
3. 对每个可选契约调用其责任 Skill 的校验器；任一契约无效时不得仅凭摘要恢复对应阶段。
4. 对照真实代码、实验、文稿或记录验证最近状态。
5. 找出最近一项 `accepted` 任务；另行说明仍处于 `executed` 的任务。
6. 汇总已确认结论、开放问题、阻断项和偏离。
7. 提出一个主原子任务和少量必要依赖。
8. 展示拟更新内容，等待用户确认。

校验失败时，不自行重建或覆盖状态。报告具体文件和错误，并把“修复状态结构”作为候选原子任务与用户讨论。

## 进度判断

- 优先相信可定位证据，不仅依赖摘要文字。
- Git 工作区存在未提交改动时，仅报告事实，不推断完成度。
- 实验日志存在但无验收记录时，最多标记为 `executed`。
- 论文段落存在但 Claim 缺乏证据时，不将论文阶段标记为 `accepted`。
- 已登记偏离没有决策记录时，保持为开放偏离。
