# 新项目初始化

## 目标

把用户给出的方向、问题、论文线索或初步 IDEA 整理为可继续讨论的项目状态草案，并确定第一项原子任务。

## 盘点内容

- 项目工作名称与项目根目录；
- AI/ML/DL 研究领域和研究类型；
- 用户当前给出的范围、问题或 IDEA；
- 已有论文、代码、数据、算力、人员和时间约束；
- 当前希望产出的研究结果；
- 明确不处理的范围；
- 当前最关键的未知项。

不强求初始化时确定投稿会议、最终论文标题或稳定 Claim。无法确定的字段使用 `null` 或 `unknowns`，不得补写推测值。

## 草案输出

给出：

1. 项目定位的一段式复述；
2. 暂定研究阶段；
3. 已知资源和约束；
4. 仍待讨论的问题；
5. 一个主原子任务及其完成标准；
6. `.cvpr/` 初始化内容摘要。

只有用户确认后才创建 `.cvpr/`。首次创建应登记一条初始化决策，并把第一任务登记为 `proposed`。
