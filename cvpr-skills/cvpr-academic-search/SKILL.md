# CVPR 学术检索

## 定位

本 Skill 是通用原子检索能力。它接收研究范围、问题证据单元、种子论文或候选论断，建立可复现的检索记录，并判断问题在最新文献中是已解决、部分解决、条件性解决、被重新定义、仍未解决，还是证据冲突。

检索结果必须可核验。搜索结果页、聚合摘要和引用次数只能用于发现线索，不能单独承担问题成立或已解决的证据。

## 工作流

### 1. 固定问题与检索截止日

记录检索问题、任务范围、纳入/排除标准、种子论文、检索截止日和目标年份窗口。拆出任务名、方法名、失败机制、数据集、指标、别名、上位词、相邻领域术语和关键作者。

“足够新”不是固定年份。默认重点覆盖检索截止日前三年的直接竞争工作，并用必要的经典论文解释问题来源；高速变化主题应缩短窗口。必须记录实际使用的截止日。

### 2. 多来源检索

优先检索论文官网、会议/期刊页面、arXiv 正文、Crossref、OpenAlex、Semantic Scholar、PubMed 等可核验来源，并做前向、后向引用追踪和相邻关键词扩展。

`cvpr-start` 调用时，补充集合必须至少含 10 篇通过身份核验和相关性筛选的论文，不计种子论文。独立调用时数量由用户目标决定。

任一来源失败都要记录来源、时间、错误和影响。可以继续使用其他已授权来源，但只有覆盖标准仍满足时才可完成；否则将任务标记为阻塞，不得声称检索完整。

### 3. 身份核验与全文取证

核验标题、作者、年份、venue、DOI/arXiv ID、版本关系和撤稿/更正状态。候选论文进入证据集前，至少要能定位到正文、附录或官方开放材料中的相关陈述或实验。

预印本与正式版本并存时建立版本关系，不重复计数。论文元数据冲突时保留冲突并继续核验，不自行选择方便的版本。

### 4. 相关性筛选与去重

先按 DOI、PMID、arXiv ID 和规范化标题去重，再按问题的直接性、证据可定位性、实验条件相似度和时效性筛选。被排除论文仍记录排除理由，避免后续重复判断。

### 5. 复查问题状态

对每个问题建立证据矩阵，至少包含支持证据、反证、解决方案、剩余失败条件、适用边界和状态判定。明确区分论文事实、作者主张和分析推断。

“存在新论文”不等于“问题已解决”；“平均指标提高”也不等于失败机制消失。必须核对原问题在相同或可比条件下是否仍出现。

### 6. 维护引用文件

以同一份文献注册表为唯一来源生成：

```text
.cvpr/literature/文献注册表.jsonl
.cvpr/literature/检索记录.md
.cvpr/literature/问题状态矩阵.yaml
.cvpr/literature/references.bib
.cvpr/literature/references.ris
.cvpr/literature/references.nbib
.cvpr/literature/引用文件核验报告.md
```

BibTeX key 必须稳定且唯一；RIS 和 BibTeX 不得补造元数据。NBIB 只写入能够映射为 PubMed/NLM 记录的文献，并在核验报告中说明覆盖率，不能用伪造 PMID 或空字段凑齐。

可按需运行 `scripts/academic_search.py`、`scripts/format-converter.py` 和 `scripts/preflight.py`。`academic_search.py` 声明 Python ≥3.10，优先使用 `uv run --script scripts/academic_search.py` 让运行时契约生效；不得用版本过低的系统 Python 强行执行。脚本输出必须回读并抽样核验；脚本失败不能改为未经核验的手工元数据。

## 完成标准

- 检索式、来源、时间窗口、截止日和排除标准可复现；
- 论文身份、版本关系、相关性和来源定位可核查；
- `cvpr-start` 场景至少有 10 篇新增合格论文；
- 每个问题都有支持、反证和状态判定；
- 引用文件由同一注册表生成并通过去重、字段和覆盖率检查；
- 已记录所有失败来源与其对结论的影响。

未满足任何强制项时，明确报告未完成，不降低门槛。
