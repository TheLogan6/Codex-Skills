# 引文解析与身份核验规范

## 目的

从用户提供的 `.docx`、`.tex`、`.bib` 或纯文本中提取引文线索，并解析到可核验的论文身份。解析结果只是候选，只有题名、作者、年份、venue 和版本关系经过来源核对后才能进入文献注册表。

## 不同文件的提取方式

### `.docx`

使用能够保留段落和域代码的文档读取工具。先识别正文引文、参考文献列表和文献管理器域代码：

- EndNote 域代码匹配 `ADDIN EN\.\w+`；
- Zotero 域代码包含结构化引用数据；
- 不把域代码本身当作正文；
- 不因清理域代码而删除用户可见的参考文献。

对清理后的文本依次识别：

| 模式 | 对象 | 示例 |
|---|---|---|
| `10\.\d{4,}/[^\s]+` | DOI | `10.1109/CVPR.2016.90` |
| `PMID:?\s*\d{7,8}` | PMID | `PMID: 27898976` |
| `PMCID:?\s*PMC\d+` | PMCID | `PMCID: PMC0000000` |
| `arXiv:\s*\d{4}\.\d{4,}(v\d+)?` | arXiv ID | `arXiv: 1706.03762v7` |

### `.tex` 与 `.bib`

至少识别：

| 模式 | 对象 |
|---|---|
| `\\cite\{([^}]+)\}` | 引用键 |
| `\\citep\{([^}]+)\}`、`\\citet\{([^}]+)\}`、`\\textcite\{([^}]+)\}` | 常见引用命令 |
| `\\bibitem\{([^}]+)\}` | 手工参考文献键 |
| `@[A-Za-z]+\{([^,]+),` | BibTeX 条目键 |
| `doi\s*=\s*\{([^}]+)\}` | DOI |
| `pmid\s*=\s*\{([^}]+)\}` | PMID |
| `eprint\s*=\s*\{([^}]+)\}` | arXiv 或其他预印本标识 |

引用键必须回到实际 `.bib` 条目解析。只有 `.tex` 而没有书目文件时，将无法解析的键标为 `manual_needed`。

### 纯文本

逐行识别 DOI、PMID、PMCID 和 arXiv ID。DOI 因换行被截断时，可以在有明确模式证据时合并相邻行，并保留原始文本定位。

没有标识符时，提取完整题名、第一作者和年份作为候选查询，不用短标题或模糊关键词直接认定论文身份。

## 解析优先级

1. DOI：通过 DOI 注册信息和出版方页面核对；
2. arXiv ID：通过 arXiv 记录核对版本；
3. PMID/PMCID：通过 NCBI 记录核对；
4. 完整题名加第一作者：使用至少一个权威元数据来源查找，再与论文正文或出版页核对；
5. 只有引用键且没有书目记录：标为 `manual_needed`。

预印本和正式版本要建立版本家族，不重复计数，也不静默丢弃较新的修订信息。

## 状态标签

| 标签 | 条件 |
|---|---|
| `verified` | 题名、作者、年份、venue 和版本关系一致 |
| `mismatch` | 找到记录，但与文档元数据存在冲突 |
| `not_found` | 在声明的来源范围内未找到匹配 |
| `suspicious` | 只有部分字段匹配或关键字段缺失 |
| `manual_needed` | 缺少足以查询的标识和题名信息 |

任何 `mismatch`、`suspicious` 或 `manual_needed` 条目都不能直接生成正式引用。
