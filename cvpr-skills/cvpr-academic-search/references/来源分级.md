# 来源分级与使用边界

## 一级：原始、可定位来源

- 会议或期刊正式论文及附录；
- arXiv 作者版本全文；
- 出版方勘误、撤稿和版本说明；
- 作者官方项目页与代码仓库中的实现记录。

一级来源承担论文身份、方法、实验、限制和问题证据。代码只能补充实现，不能替代论文论断。

## 二级：结构化学术索引

- Crossref；
- OpenAlex；
- Semantic Scholar；
- PubMed；
- DBLP 等领域索引。

二级来源用于发现论文、核对元数据、追踪引用和构建候选集合。索引摘要或引用次数不能单独证明研究问题。

## 三级：发现线索来源

- 搜索引擎结果；
- 聚合页面；
- 新闻、博客、社交媒体和二手综述；
- 不稳定或需要人工访问的检索入口。

三级来源只用于发现关键词和潜在线索。候选内容必须回到一级或可靠二级来源核验后才能进入证据集。

## 访问失败

来源失败时记录来源、时间、查询、错误和影响。是否继续由当前任务的覆盖标准决定：

- 其他来源能够独立满足既定覆盖和证据要求时，可以继续，但报告缺失来源；
- 关键 venue、年份或证据类型因此不可覆盖时，任务为 `blocked` 或 `partial`；
- 不得自动把低等级来源当成等价证据，也不得把部分结果表述为完整检索。

## 身份冲突

标题、作者、年份、DOI、arXiv ID 或版本关系冲突时，以论文官网、出版方和作者版本记录交叉核对。无法消解时保留冲突状态，不将该记录用于强结论。
