# 检索与时效性规范

## 检索截止日

每次任务写明实际检索截止日，所有“最新”“近期”“尚未解决”的判断只对该日期成立。

默认时间结构：

- 直接竞争工作：重点覆盖截止日前三年；
- 快速变化主题：根据模型、数据集或评测迭代速度缩短至一至两年；
- 经典锚点：不限年份，但只用于定义问题、方法谱系或关键基准；
- 截止日之后的论文：不得假定存在或纳入。

不得仅按年份筛选。正式版本较晚但预印本较早时记录二者，说明采用哪个日期回答“时效性”。

## 检索覆盖

至少覆盖：

- 任务和方法的精确术语；
- 同义词、旧名、缩写和相邻领域术语；
- 种子论文的后向参考文献和前向引用；
- 关键作者、实验基准和失败机制；
- 反向查询，例如“limitation”“failure”“does not”“underperform”“robustness”“generalization”。

每组查询记录来源、完整检索式、过滤条件、时间和返回数量。

## 近期性判断

“新”只说明发表时间，不说明相关性或证据质量。每篇近期论文仍需通过：

1. 身份与版本核验；
2. 与目标问题的直接相关性；
3. 正文证据可定位性；
4. 实验条件可比性；
5. 撤稿、更正和争议检查。

## 完整性边界

如果关键数据库、会议论文集或目标年份无法访问，必须说明缺口对结论的影响。其他来源可以补充证据，但不能把未知覆盖写成“已全面检索”。
