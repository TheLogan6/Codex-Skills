# 文献去重与版本关系规范

## 目标

去重的目的是识别同一研究记录和不同版本之间的关系，不是为了把冲突字段简单覆盖。每次合并都要保留来源、原值和裁决依据。

## 身份键优先级

### 1. 强标识符

按以下顺序规范化：

- DOI：去掉 `https://doi.org/`，转为小写，清理尾部标点；
- arXiv ID：保留基础 ID，同时单独记录版本号；
- PMID 与 PMCID：按数字或规范 ID 保存；
- 出版方稳定 article ID。

同一类强标识符一致时，可以判定为同一记录。两个不同 DOI 不能只因标题相似就自动合并。

### 2. 题名、作者与年份

缺少共同强标识符时：

1. 规范化 Unicode、大小写、空白和不影响语义的标点；
2. 比较完整题名，不删除模型名、数据集名、版本号或任务限定词；
3. 比较第一作者及作者序列；
4. 核对年份、venue 和页码；
5. 使用字符串相似度只生成“疑似重复”，再人工或 Agent 复核。

标题相似度阈值不能单独承担自动合并决定。

## 版本家族

预印本、会议版、期刊扩展版、更正版和撤稿记录要放入同一 `version_family`，分别保存：

- 版本标识与日期；
- 正文和附录是否变化；
- 题名和作者变化；
- 正式出版关系；
- 更正、撤稿或更新状态；
- 当前分析实际采用的版本。

版本家族在数量统计中只计一个研究工作，但证据定位必须指向实际读取的版本。

## 字段合并

每个字段保存来源。冲突时按证据裁决：

1. 论文正式页面或正文；
2. DOI、arXiv、PubMed 等权威注册记录；
3. 作者官方页面或官方仓库；
4. 其他聚合元数据。

不要使用引用次数决定哪个元数据更真实。无法裁决时保留冲突，状态设为 `conflicting`。

## 输出要求

文献注册表至少保留：

```text
paper_id
version_family_id
canonical_title
identifiers
authors
year
venue
version_used
source_records
field_conflicts
dedup_decision
dedup_evidence
```

被排除或合并的原记录仍应能从 `source_records` 找回。
