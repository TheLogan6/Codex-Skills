# `.nbib`、RIS 与 BibTeX 格式规范

## 总原则

三种引用文件必须来自同一份已核验文献注册表。不得为了补齐格式而虚构 DOI、PMID、页码、作者、年份或 venue。

`.nbib` 只覆盖存在 PubMed/NLM 记录的论文；覆盖不足是正常事实，要在核验报告中说明。RIS 和 BibTeX 可以覆盖其他已核验来源。

## RIS

RIS 可供 EndNote、Zotero 和多数文献管理器导入。

```text
TY  - JOUR
AU  - Last, First
AU  - Last2, First2
TI  - Article Title
JO  - Journal or Proceedings Name
PY  - 2024
VL  - 10
IS  - 3
SP  - 123
EP  - 145
DO  - 10.1234/example
UR  - https://doi.org/10.1234/example
AB  - Abstract text
KW  - keyword
AN  - PMID:12345678
DB  - PubMed
ER  -
```

每条记录必须以 `ER  -` 和一个空行结束。不存在的字段不输出空占位。

### MEDLINE 到 RIS

| MEDLINE | RIS | 处理 |
|---|---|---|
| `PMID-` | `AN  - PMID:` | 保存 PMID |
| `TI  -` | `TI  -` | 保留完整题名 |
| `AU  -` | `AU  -` | 每位作者一行 |
| `JT  -` | `JO  -` | 完整刊名 |
| `TA  -` | `JA  -` | 刊名缩写 |
| `DP  -` | `PY  -` | 提取四位年份 |
| `VI  -` | `VL  -` | 卷 |
| `IP  -` | `IS  -` | 期 |
| `PG  -` | `SP  -`、`EP  -` | 有明确范围时拆分页码 |
| `AB  -` | `AB  -` | 摘要 |
| `MH  -` | `KW  -` | MeSH 词作为关键词 |
| `LID -`、`AID -` | `DO  -` | 只接受带 `[doi]` 的 DOI 值 |

## BibTeX

```bibtex
@article{firstauthor2024shorttitle,
  author  = {Last, First and Last2, First2},
  title   = {{Article Title}},
  journal = {Journal Name},
  year    = {2024},
  volume  = {10},
  number  = {3},
  pages   = {123--145},
  doi     = {10.1234/example},
  url     = {https://doi.org/10.1234/example},
  pmid    = {12345678}
}
```

### 引用键

- 优先使用 `第一作者姓 + 年份 + 短标题词`；
- 转为小写 ASCII，移除空格和标点；
- 同一注册表中必须唯一；
- 冲突时追加有意义的短词，仍冲突才使用 `a`、`b`；
- 已在项目中使用的稳定键不要无理由重命名。

### 清理

- 作者之间使用 ` and `；
- 页码范围使用 `--`；
- 保护题名中的模型名、数据集名和必要大写；
- 对 `&` 等 LaTeX 特殊字符正确转义；
- 去掉摘要中的 HTML 标签；
- 不截断题名、作者、DOI 或 venue；
- 合并时不静默覆盖键或字段冲突。

## `.nbib`

`.nbib` 使用 NLM/MEDLINE 标签。至少保留能够从 PubMed 核验到的：

```text
PMID
TI
AU 或 FAU
DP
JT 或 TA
LID/AID 中的 DOI
PT
```

不要为非 PubMed 论文伪造 PMID，也不要把 arXiv ID 写入 PMID 字段。

## 文件核验报告

每次生成引用文件后报告：

- 注册表总记录数；
- `.bib` 与 `.ris` 的输出数；
- `.nbib` 可映射数和未覆盖原因；
- 去重与版本家族数量；
- 缺失字段、字段冲突和键冲突；
- 抽样回查的论文与来源。
