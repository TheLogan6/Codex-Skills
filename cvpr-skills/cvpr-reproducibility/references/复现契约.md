# 复现契约

模板位于 `assets/复现任务模板/reproducibility.yaml`，采用 JSON 表达以保证确定性读取，同时也是 YAML 1.2 的有效子集。

## 权威关系

- `source_snapshot` 只引用 `cvpr-result` 冻结快照，不复制或修改 DO 的 Goal 判定。
- `source_snapshot.freshness` 只允许 `current` 或 `stale`；正式状态必须为 `current`。
- `materials` 记录材料事实；`category_assessments` 记录十二类覆盖状态。
- `availability_assertions` 是 URL、标识符、许可证和公开状态的唯一核验记录。
- `statements` 只组织措辞，不得制造新的可用性事实。
- `gaps` 与 `risks` 保留阻断项，不能因生成声明而删除。

## 状态

- `proposed`：可用于尚未完成的局部清点；
- `reviewed`：材料审计完成，但声明或发布尚未确认；
- `accepted`：用户已确认当前复现记录；
- `blocked`：关键事实或材料缺失；
- `superseded`：被新快照或新版本替代。

`reviewed` 和 `accepted` 必须绑定已接受的冻结 Result，覆盖全部十二类材料，且每个 `unknown` 或 `partial` 都有 gap。`accepted` 不代表所有材料公开。

Result 的 `snapshot_id` 变化后，旧记录必须将 `freshness` 设为 `stale` 并转为 `superseded`，不能继续作为当前论文材料。

## 路径

项目内文件使用相对路径，禁止 `..`、绝对路径和用户主目录。外部标识放在 `availability_assertions`，不要伪装成本地路径。

## 保护

敏感或受限材料必须设置 `sensitive: true`，并且不得标记为 `public`。公开输出只能引用 `public_export_allowed: true` 的材料。契约不保存 secret、token、password、API key 或个人支付/联系信息。
