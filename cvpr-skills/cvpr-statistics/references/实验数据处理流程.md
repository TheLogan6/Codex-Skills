# 实验数据处理流程

## 输入盘点

建立输入清单：

- 冻结快照；
- Run ID；
- 原始输出；
- 配置和 checkpoint；
- 数据或实验对象；
- 指标实现；
- 环境与代码版本；
- 失败、终止和偏离。

区分原始结果、处理中间结果、汇总结果和人工记录。人工转录数字必须能回到机器可读来源。

## 统一数据粒度

先定义一行数据代表什么，再做聚合。常见粒度包括：

- 一个 seed 的一次完整训练与评测；
- 一个模型在一个任务或数据集上的评测；
- 一个 episode 或场景；
- 一个样本或评价项目；
- 一个评价者对一个项目的评分。

混合粒度必须拆表或显式标记，不能在同一列直接平均。

## 处理顺序

1. 读取原始结果并保存来源定位；
2. 检查字段、类型、单位和主键；
3. 核对重复、缺失、失败和异常；
4. 应用预先确定的纳入与排除规则；
5. 计算单次 Run 或单个单位指标；
6. 按实验设计聚合；
7. 计算不确定性、效应量或检验；
8. 生成结构化表；
9. 反向抽查表格数字到原始结果；
10. 保存代码、配置和统计任务契约。

## 运行条件对齐

比较前核对：

- 数据、划分和预处理；
- evaluator 版本；
- 模型和 checkpoint 选择；
- 训练或适配预算；
- seed 集合；
- 硬件和运行时条件；
- 任务、场景和样本集合；
- 后处理、阈值和聚合方式。

条件不可比时不得把差值解释为方法贡献。

## 重复执行

相同冻结快照和相同统计配置应产生相同结果。随机重采样方法必须固定并登记随机种子。

重新生成表格时不要覆盖无法定位的旧版本；通过分析 ID、版本或结果目录保留关系。
