# CVPR 论文分析

## 定位

本 Skill 是可独立调用的原子研究能力，也可由 `cvpr-start` 调用。论文全文是第一来源；附录、补充材料和官方代码用于补证，摘要、README、媒体报道和二手解读不能代替全文。

本 Skill 负责“读懂并抽取证据”，不负责扩展检索、候选 IDEA 决策、语言人类化或论文写作。多篇论文既要逐篇分析，也要在统一问题轴上比较，不能把若干摘要拼成综述。

## 工作流

### 1. 确认论文身份和材料

逐篇记录标题、作者、年份、会议或期刊、版本、DOI/arXiv ID、正文、附录、补充材料和官方仓库。正文版本冲突时明确实际采用的版本。

无法获得全文时，停止该论文的“全文分析”，明确列出已获得和缺失的材料。不得用摘要或仓库补成完整结论。

### 2. 三遍研读

按结构通读、因果重构、证据审计完成全文阅读。还原：

```text
观察到的问题 → 原因判断 → 关键假设 → 设计选择
→ 中间机制 → 预期效果 → 实验证据 → 适用边界
```

实验部分同时检查对照公平性、数据泄漏、训练预算、硬件、输入尺度、统计波动、消融、效率、泛化和失败案例。

### 3. 区分三类陈述

每个关键判断必须标记为：

- `论文事实`：正文、表格、图、公式或附录可直接定位的内容；
- `作者主张`：作者给出的解释、归因或外推；
- `分析推断`：基于论文证据形成、但原文未直接声称的判断。

分析推断必须写出推断链和不确定性，不能改写成论文已证明的事实。

### 4. 生成问题证据单元

问题不能只写成“性能不足”或“泛化较差”。每个问题证据单元必须包含原文定位、证据类型、成立条件、影响对象、当前解决状态、反证或替代解释，以及可验证方式。

### 5. 多论文综合

先完成逐篇证据单元，再统一术语和比较维度。区分：

- 多篇论文共同明确承认的问题；
- 只在特定数据、模型、预算或评测设置下出现的问题；
- 结论冲突及其可能来源；
- 新方法已解决、部分解决、条件性解决、重新定义或仍未解决的问题；
- 由跨论文对照得到、尚需补证的分析假设。

### 6. 写入项目状态

项目存在 `.cvpr/` 且调用方要求长期记录时，将结构化分析写入调用方指定位置，并在 `.cvpr/claims.yaml` 登记关键论断及证据定位。不得直接把分析结果标记为已验收 IDEA。

## 输出契约

至少输出：

1. 论文身份与材料完整性；
2. 逐篇问题—方法—机制—证据链；
3. 关键结果、失败案例和边界；
4. 事实、作者主张、分析推断的分离记录；
5. 多论文共性、矛盾和问题状态；
6. 可供 `cvpr-academic-search` 使用的检索概念、同义词、关键作者和引用链入口；
7. 问题证据单元清单。

数量服从证据，不为凑数制造问题。

## 停止条件

出现全文缺失、版本无法确认、核心实验不可定位或材料互相冲突时，明确停止受影响的结论。不得自动降低为摘要分析，也不得静默省略。
