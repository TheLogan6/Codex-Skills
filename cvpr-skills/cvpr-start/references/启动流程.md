# 启动流程

## 输入类型

### 研究范围

先把范围分解为任务、对象、约束、失败表现、评价方式和潜在使用场景，再交给检索流程形成种子文献集。范围可以宽，但首次候选 IDEA 必须落到可检验问题。

### 一篇或多篇种子论文

逐篇确认全文和版本，调用 `cvpr-paper-analysis`。多篇论文先独立研读，再做共性与矛盾综合。

## 阶段记录

每一步记录输入版本、工具或 Skill、时间、结果、证据位置、未完成项和对下一步的影响：

```text
S1 种子问题凝练
S2 新增文献检索与问题复查
S3 用户材料初步核验或显式跳过
S4 候选 IDEA 证据卡
S5 多 Agent 审查与修订
S6 用户讨论与最终确认
```

## 回退规则

这里的“回退”是证据驱动的返工，不是降低要求：

- 新文献显示问题已解决：重写问题或取消候选；
- 证据不足：继续检索；
- 用户材料不支持问题：分析条件差异或取消候选；
- 审查发现新颖性或可行性缺陷：补证、缩小范围或重构；
- 五轮未收敛：标记 `needs-reframing`。

不得自动减少十篇文献、五个候选、证据门槛或多 Agent 审查。

## 阶段完成

只有用户明确确认最终 IDEA，且初步验收目标、反证条件和边界已写清，启动阶段才完成。此时可以把后续行动计划作为下一个原子任务提出，但不在本 Skill 内直接执行工程工作。
