# 编译、匿名与版面 QA

## 编译记录

使用模板支持的引擎和项目现有构建方式。记录完整命令、工作目录、引擎版本、返回码、产物和日志。编译成功至少要求：

- 主构建返回码为 0；
- 无 LaTeX error、emergency stop 或缺失输入文件；
- 引用与交叉引用已收敛；
- bibliography 实际生成；
- 输出 PDF 页数大于 0；
- 关键 warning 已分类，阻断 warning 为 0。

不能删除日志来制造“clean build”。

## 匿名检查

按目标官方规则检查：

- 作者、机构、邮箱、致谢、基金、伦理机构和算力平台名称；
- 自引措辞、公开项目链接、个人主页、仓库组织和 artifact metadata；
- PDF Author/Creator/Producer、附件和注释；
- 图片 EXIF、源文件路径、日志绝对路径和补充文件名；
- reviewer link 是否泄露账号或可编辑身份。

匿名审稿版与 camera-ready 版分离。记录被隐藏内容及恢复位置，不永久删除作者信息源。

## 版面诊断

每次有布局改动后：

1. 重新编译并读取日志；
2. 将全部 PDF 页面渲染成图片；
3. 生成接触表或逐页索引；
4. 目视检查全部页面；
5. 对问题页回查 `.tex`、资源尺寸和日志；
6. 修改后重复全链路。

重点检查 overfull/underfull、float too large、未定义引用、孤立标题、错误空白页、图表裁切、跨栏错位、正文与图表顺序、脚注、页码和补充材料边界。

## 安全调整

优先允许：

- 消除多余空白、重复换页和不必要浮动屏障；
- 在官方模板允许范围内调整浮动位置；
- 重新组织多面板布局但不修改数据；
- 从源头生成适合栏宽的图形；
- 修复资源路径、引用顺序和 package 冲突。

必须回交用户或内容 Skill：

- 删除或重写科研内容；
- 改变表格数字、显著性或图形含义；
- 把必要实验移出正文；
- 改变 Claim 强度；
- 为页数减少引用或限制讨论。

禁止篡改官方边距、字号、行距或样式文件来过页。

## 通过条件

`qa_passed` 或 `accepted` 要求完整编译成功、所有页面已渲染检查、页数合规、匿名检查适用于当前 stage、没有阻断问题、所有输出可定位。
