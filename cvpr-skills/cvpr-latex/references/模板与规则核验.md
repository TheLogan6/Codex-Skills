# 模板与规则核验

## 核验对象

正式任务必须固定以下五元组：

`venue + track + year/edition + submission stage + official source`

同一 venue 的 workshop、main track、findings、demo、dataset track、review 和 camera-ready 规则可能不同，不得互相替代。

## 来源顺序

优先使用：

1. venue 当年官方 author instructions；
2. 官方 style/template 下载页或官方组织代码仓库；
3. 官方 submission system 中的说明；
4. 官方 FAQ 或 chair 公告。

第三方 Overleaf 模板、往年仓库、博客或其他论文只可辅助定位，不能作为最终规则依据。规则会变化；最终组装时重新核验并记录日期。

## 模板记录

保存：

- 官方来源 URL 或已下载附件的证据引用；
- 获取日期、版本/tag/commit 或文件校验和；
- 主入口、样式文件、参考文献样式和许可证；
- 官方示例与用户工程之间的差异；
- review 与 camera-ready 开关；
- 本地存放路径，不覆盖原始模板副本。

不得自制一个通用模板冒充官方模板。若官方只提供 Word 或在线编辑方式，应如实报告而不是转造 LaTeX。

## 规则清单

至少提取：

- 正文页数、哪些部分计入页数；
- 双栏/单栏、纸张、边距、字号、行距；
- 匿名、自引、致谢、基金和补充链接要求；
- 图表、附录、补充材料和 checklist 规则；
- 文件格式、大小、命名与 PDF 合规要求；
- 引用、版权、伦理、生成式 AI 或资源声明要求；
- camera-ready 与 review 的差异。

每条规则绑定官方来源位置。没有来源的推断标记为 unresolved。

## 迁移

模板迁移时先建立内容映射，再迁移章节和资源。不要复制旧模板的 preamble、页眉页脚或自定义边距命令。逐项核对 package 冲突、参考文献命令、附录切换、匿名开关和官方 checklist。
