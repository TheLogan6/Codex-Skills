# CVPR LaTeX

## 定位

作为可独立调用的论文排版原子能力，将已经确认的科研内容安全组装为目标 venue 可编译、可检查的 LaTeX 工程和 PDF。包名中的 CVPR 是工作流品牌，不把模板、页数或会议规则写死为 CVPR。

不撰写或改写科研结论，不修改实验数字，不替 `cvpr-do` 或 `cvpr-result` 判断目标，不以版面压力为由静默删减内容。

## 必读规范

- 获取、选择或迁移模板时读取 [模板与规则核验.md](references/模板与规则核验.md)。
- 编译、匿名化或版面调整时读取 [编译、匿名与版面QA.md](references/编译、匿名与版面QA.md)。
- 创建机器记录时读取 [LaTeX组装契约.md](references/LaTeX组装契约.md)。

## 输入门禁

正式组装前必须确认：

- 目标 venue、track、年份和 `review` / `camera_ready` stage；
- 官方规则来源及核验日期；
- 官方模板来源、版本和本地路径；
- 已冻结且已接受的 Result `snapshot_id`；
- 当前正文、参考文献、表格、图形、附录和补充材料来源。

目标或模板缺失时，向用户说明缺失信息并暂停正式组装；不能静默套用通用 `article`、旧年份模板或相似会议模板。会议规则具有时效性，正式使用时必须核验官方来源。

## 工作模式

- `assemble`：把已确认内容组装进官方模板。
- `venue_migration`：在两个明确模板之间迁移，保留内容与来源映射。
- `compile`：修复确定性的编译、引用和资源问题。
- `anonymization_audit`：检查稿件、元数据、资源和链接中的身份线索。
- `layout_audit`：检查页数、双栏、浮动体、溢出、字体和逐页视觉质量。
- `supplementary`：组织附录或独立补充材料及交叉引用。

## 工作流

### 1. 冻结内容输入

建立 `snapshot_id` 和输入资产清单。正文句子、数字、图表、公式与引用的内容权威仍属于相应上游产物；本 Skill 只保存组装位置和布局变更。

### 2. 核验模板与规则

记录官方来源、获取日期、模板版本或校验和、venue、track、年份和 stage。区分页数范围、匿名要求、补充材料规则、文件命名、字体/边距限制和 checklist。

规则无法核验时保持 `proposed` 或 `blocked`，不能生成“符合投稿要求”的结论。

### 3. 组装且保护科研内容

复制或引用官方模板文件，组装章节、公式、表格、图形、参考文献、附录和补充材料。记录每项布局修改；任何内容变化必须停止并交回 `cvpr-writing`、`cvpr-citation`、`cvpr-statistics` 或 `cvpr-figure`。

不得为过页静默删句、改数字、缩小模板规定字号、压缩边距或覆盖官方样式。

### 4. 编译

使用项目记录的编译引擎和官方模板要求执行完整编译链，保存命令、返回码、日志、警告、引用状态和 PDF。不要只运行一次 LaTeX 后忽略未解析引用。

### 5. 匿名化审计

审计正文、致谢、自引、仓库链接、PDF 元数据、图片元数据、补充材料、文件路径和编译日志。只删除或替换目标规则明确要求隐藏的身份信息，并保留 camera-ready 恢复记录。

### 6. 渲染与逐页 QA

遵循 `修改 → 编译 → 渲染 → 查看 → 复查日志`。渲染全部页面并建立接触表或等效逐页索引，检查：

- 缺页、空白页、裁切、溢出和不可读文本；
- 浮动体顺序、跨栏图表、标题与正文脱节；
- 双栏、页码、字体、边距、页数和补充材料边界；
- 公式、引用、交叉引用、图表和颜色可读性。

不能只看 `.tex` 或编译返回码判定版面通过。

### 7. 写入产物并校验

建议写入：

```text
cvpr_workspace/paper/latex/
├── source/
├── build/
├── render/
└── latex-assembly.yaml
```

从 [LaTeX 组装模板](assets/LaTeX组装模板/latex-assembly.yaml) 建立记录，运行：

```bash
python3 <cvpr-latex目录>/scripts/validate_latex_manifest.py \
  <项目根目录>/cvpr_workspace/paper/latex/latex-assembly.yaml \
  --project-root <项目根目录>
```

## 过页处理

按以下顺序呈报并处理：

1. 定位页数归属和主要占用来源；
2. 修复真实排版浪费、异常浮动和不必要的重复版式；
3. 调整图表布局但保持数据与可读性；
4. 将需要内容删改或结构压缩的事项交回用户与写作能力讨论。

禁止自动降低字号、缩边距、压行距、隐藏必要内容或把正文挪入不允许的补充材料。

## 完成标准

- venue、track、年份、stage、官方规则和模板均已核验；
- 正式产物绑定冻结 Result 快照；
- LaTeX 编译链成功，引用和交叉引用已收敛；
- 匿名要求按目标 stage 通过；
- 页数及版式符合已核验规则；
- 全部页面完成真实渲染 QA，没有未解决阻断问题；
- 源码、PDF、日志、渲染结果与审计报告可定位；
- 没有未经授权的科研内容变更；
- 机器契约校验通过。
