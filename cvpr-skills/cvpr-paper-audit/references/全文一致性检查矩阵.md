# 全文一致性检查矩阵

## 必查类别

| 类别 | 核心问题 |
|---|---|
| `manuscript_completeness` | 目标稿件、附录、补充材料、匿名信息和必要章节是否齐全 |
| `claim_evidence` | 每项核心 Claim 是否绑定真实实验、代码、图表或已核验文献，强度是否越界 |
| `number_traceability` | 正文数字是否能回溯到统计产物、表格源数据和具体 Run |
| `table_consistency` | 表内、表注、正文引用和统计源是否一致，比较条件是否完整 |
| `figure_consistency` | 图、图注、panel、正文描述和源数据是否一致 |
| `formula_consistency` | 公式、符号、维度、下标、定义及代码实现对应关系是否一致 |
| `citation_support` | 引用是否真实存在、位置准确并真正支持相邻论断 |
| `terminology_consistency` | 模型、模块、数据集、指标、缩写和符号是否使用唯一名称 |
| `run_alignment` | 论文采用的 Run 是否属于冻结结果，配置、划分和 checkpoint 是否匹配 |
| `statistics_alignment` | 汇总方式、样本单位、不确定性、显著性和效应量是否与统计产物一致 |
| `reproducibility_alignment` | 代码、数据、环境、配置、权重、入口和可用性声明是否与实际材料一致 |

## 严重性

- `blocker`：会使核心结论、关键数字或材料真实性无法确认，或输入不足以完成审计。
- `major`：足以误导主要 Claim、比较、公平性、统计解释或复现性，必须在进入科学审稿前修复。
- `minor`：不改变核心结论，但会造成定位、术语、格式或局部解释错误。

严重性依据影响确定，不依据修复工作量。

## 证据强度

问题证据至少指向以下之一：

- 冻结稿件中的精确位置；
- 权威账本条目；
- 原始 Run、配置、日志或 checkpoint；
- 统计任务及其输出；
- 图表源数据和生成记录；
- 已核验的文献条目；
- 复现材料清单和实际文件。

缺失本身可以成为证据，但必须列出预期材料、已检查位置和为何阻断。

## 禁止事项

- 不把措辞偏好升级为证据错误；
- 不用重新计算得到的新口径覆盖冻结统计产物；
- 不因图表视觉合理就认定数据一致；
- 不因引用主题相关就认定其支持具体论断；
- 不用大多数检查通过掩盖单个 blocker；
- 不输出会议录用概率或 accept/reject 建议。
