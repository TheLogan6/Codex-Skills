# CVPR Citation

将本 Skill 作为原子级论断—文献绑定能力。它消费 `cvpr-academic-search` 已核验的文献注册表及 `.bib/.ris/.nbib` 文件，不复制其检索职责。

## 硬性边界

- 不凭记忆创建引用、BibTeX、作者、标题、年份、DOI、arXiv ID 或 venue。
- “主题相关”不等于“支持论断”。必须检查摘要、正文或可靠的全文定位后再判断支持级别。
- 元数据已核验但内容未核验的论文不得作为论断支持插入正文。
- 在 `.cvpr` 项目中引用冻结 `snapshot_ref` 和 `.cvpr/claims.yaml`；不得修改 Goal、DO 或 Result 判定。
- 缺少支持文献时登记 `needs_academic_search`，说明检索问题，再交给 `cvpr-academic-search`；不得自动降低核验标准。
- 不撰写新的科学结论，不做统计、绘图、语言润色、LaTeX 布局或审稿，不提供时间预估。

## 执行流程

1. **冻结输入。** 记录稿件、Claim 账本、快照以及已核验文献注册表和引用文件。
2. **拆分论断。** 将长句拆成可独立核验的最小事实单元；区分事实、方法归属、背景、比较、解释和作者自身结果。
3. **读取核验记录。** 每篇可用论文必须具有稳定 `paper_id`、元数据来源、内容证据来源和唯一 `bibtex_key`。
4. **判定支持。** 按 [论断拆分与支持等级](references/论断拆分与支持等级.md) 标记 `direct`、`partial`、`contextual`、`contradictory`、`topical_only` 或 `not_supporting`。
5. **决定插入。** 只把满足引用角色的已核验证据写入正文；矛盾文献只能以对比或限制角色引用，不能伪装为正向支持。
6. **维护书目。** 依据已核验记录复用或分配唯一引用键；合并 `.bib/.ris/.nbib` 时保留来源，检测重复、字段冲突和键冲突。规则见 [文献注册与书目契约](references/文献注册与书目契约.md)。
7. **报告覆盖。** 对每个论断给出覆盖状态、插入引用、证据定位、冲突和检索缺口。插入规则见 [引用插入与冲突处理](references/引用插入与冲突处理.md)。
8. **保存并校验。** 使用 [引用任务模板](assets/引用任务模板/citation.yaml)，运行：

```bash
python3 <cvpr-citation-Skill目录>/scripts/validate_citation_manifest.py \
  <citation.yaml> --project-root <项目根目录>
```

## 完成标准

- 所有目标论断均有独立覆盖状态；
- 每个已插入引用都指向已核验文献和具体内容证据；
- `topical_only`、`not_supporting` 和未核验记录未被插入；
- 引用键唯一且与书目记录一致；
- 缺口和冲突显式呈报，没有伪造或隐式占位引用；
- 任务契约通过确定性校验。
