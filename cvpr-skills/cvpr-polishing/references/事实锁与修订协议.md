# 事实锁与修订协议

## 锁定对象

### 字面锁

原则上要求源文与输出保持同一值：

- `numeric`：数值、正负号、小数点、百分比、范围和样本量；
- `unit`：单位及量纲；
- `formula`：公式、变量和上下标含义；
- `citation`：引用键、编号和来源归属；
- `identifier`：模型、数据集、基准、版本、Run ID 和配置名。

### 语义锁

允许换词，但语义强度必须等价：

- `technical_term`；
- `comparison`；
- `modality`；
- `negation`；
- `evidence_strength`；
- `causality`;
- `scope_condition`。

每个锁记录源值、输出值、源/输出定位、状态和核对说明。字面锁应为 `preserved`；语义锁可为 `verified_equivalent`。`changed` 不能出现在完成任务中。

## 处理疑似错误

若源文的数字、公式或事实疑似错误：

1. 保留原值；
2. 标记阻断或问题；
3. 给出证据定位；
4. 交给写作、统计、引用或上游研究 Skill 核实。

润色不能借“纠错”越权改动研究事实。
