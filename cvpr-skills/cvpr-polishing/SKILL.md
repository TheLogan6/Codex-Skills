# CVPR Polishing

将本 Skill 作为原子级学术表达能力。名称中的 CVPR 是工作流品牌，不限定 venue；根据当前论文类型、章节和语言方向工作。

## 硬性边界

- 先建立事实锁，再修改语言。数字、单位、公式、引用键、技术实体、实验条件、比较关系、否定词、模态和证据强度必须保持。
- 不把相关改成因果、观察改成证明、局部结果改成普遍结论、趋势改成显著差异、可能改成确定。
- 不新增方法、实验、结果、引用、贡献或作者行为；不修改 Goal、DO、Result 或 Claim 权威账本。
- 正文作者主体使用“我们”或 `we`；但源文没有作者行为时不得为了第一人称强行增加。
- 不处理 LaTeX 布局、模板、浮动体或编译；交给 `cvpr-latex`。
- 不自动降低质量标准，不提供时间预估。

## 模式

- `polish`：改善表达而不改变段落科学结构。
- `restructure`：重排句段以改善论证流；若需要新增证据才能成立，则停止并报告。
- `translate_zh_to_en`：以科学语义等价为第一目标完成中译英。

## 执行流程

1. **识别范围。** 确定模式、章节、源语言、目标语言和目标 venue；venue 只影响风格约束，不改变事实。
2. **读取证据边界。** CVPR 项目内引用冻结 `snapshot_ref` 和 Claim 账本；独立调用时记录材料范围。
3. **建立事实锁。** 提取所有不可变数字、单位、公式、引用、实体、技术术语、比较方向、模态和证据强度。详细规则见 [事实锁与修订协议](references/事实锁与修订协议.md)。
4. **诊断后修改。** 先判断问题属于段落职责、信息顺序、指代、术语还是句法，再按 [学术表达与翻译规范](references/学术表达与翻译规范.md) 修订。
5. **逐项回查。** 比较源文与修订稿，确认每个事实锁保持；发现疑似事实更正需求时不代改，返回 `cvpr-writing` 或上游研究环节。
6. **可选人类化。** 只有用户明确要求或上层路由明确组合时才调用 `cvpr-humanizer`；调用后必须再次执行完整事实锁。见 [人类化组合与交付](references/人类化组合与交付.md)。
7. **交付。** 提供修订稿、关键修改摘要、事实锁报告和无法仅靠语言解决的问题。
8. **保存并校验。** 使用 [润色任务模板](assets/润色任务模板/polishing.yaml)，运行：

```bash
python3 <cvpr-polishing-Skill目录>/scripts/validate_polishing_manifest.py \
  <polishing.yaml> --project-root <项目根目录>
```

## 完成标准

- 每个事实锁均验证保持，且输出不存在未经授权的科学内容；
- 术语、缩写和论文人称一致；
- 译文或修订稿保留原文模态、否定、比较条件与证据强度；
- `cvpr-humanizer` 若被调用，调用后重新通过事实锁；
- LaTeX 版面问题未被混入语言修改；
- 任务契约通过确定性校验。
