# 视觉与统计完整性

## 坐标和尺度

- 比较绝对大小的普通柱状图原则上从零开始；
- 差值、收敛或局部变化使用聚焦尺度时，必须明确标注并保留准确值；
- 相互比较的面板保持一致尺度，除非差异被明确说明；
- 对数轴、断轴和归一化必须可见；
- 不使用面积或体积夸大一维数值差异。

## 不确定性

每个误差条或区间必须说明：

- 表示的统计量；
- 实验单位；
- 样本量或 Run 数；
- 计算方法；
- 是否配对；
- 置信水平或分位范围。

图形只读取已经审核的统计值，不在绘图脚本中临时改用另一种误差。

## 数据选择

- 显示的配置、样本和运行集合与来源表一致；
- 省略项需要在契约和图注中解释；
- 不能只展示本方法成功、baseline 失败的案例；
- 失败点不能因破坏版式而删除；
- 缺失值与零值使用不同视觉语义。

## 颜色与可访问性

- 不只依赖颜色区分关键系列；
- 同时使用线型、标记、填充、直接标签、排序或分面；
- 避免默认红绿语义；
- 限制无意义的多色；
- 检查灰度或非颜色通道。

## 标签与精度

- 标明指标方向、单位和条件；
- 数值精度与测量精度一致；
- 图例名称与结果表一致；
- 标题或图内文字不先行宣称超出数据的结论；
- 图注事实可以由论文 Skill 编写，但必须基于图形契约。

## 定性完整性

裁剪、缩放、颜色映射和后处理保持可比。任何增强、拼接或遮挡都需登记。不能通过不同裁剪或色阶使本方法看起来更好。
