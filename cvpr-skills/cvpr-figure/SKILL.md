# CVPR 科研绘图

## 定位

保持原子化。接收已审核数据和明确图形任务，生成绘图代码、图形源数据、可编辑输出、交付格式和视觉 QA 记录。可由 `cvpr-result` 和后续论文 Skill 重复调用。

采用“先定义证据结论、后选图形、固定后端、渲染后检查”的工作框架，面向通用 AI/ML/DL 会议与论文图形，不预设特定期刊或会议的视觉要求。

## 输入门禁

开始绘图前确认：

- 图形用途和要帮助读者完成的比较；
- 来源快照、结构化数据、Run 和统计任务可定位；
- 每个指标的定义、方向、单位、样本量和不确定性；
- 数据是否已通过 `cvpr-result` 或 `cvpr-statistics` 审核；
- Python 或 R 后端已经由用户选择，或项目已有明确唯一绘图后端。

没有明确后端且项目也没有既定后端时，只询问“使用 Python 还是 R？”，不默认选择。

`result_presentation` 和 `paper` 模式只接受 `reviewed` 数据。探索性数据只能生成 `exploratory` 图形，不能登记为论文或 Result 正式产物。

## 工作流

### 1. 定义图形契约

绘图前写清：

- 图形目的；
- 支持的 Claim；
- 数据来源；
- 读者需要比较什么；
- 面板及证据关系；
- 统计和误差表达；
- 输出尺寸、格式和使用位置；
- 可能误导读者的风险。

一张图可以呈现多项证据，但不能把互不相关的结果拼成没有中心问题的面板集合。

### 2. 冻结图形源数据

从已审核结果包提取图形所需的数据切片，保存到：

```text
cvpr_workspace/result_package/figures/data/
```

绘图脚本不得直接从易变化的终端输出、手工复制数字或未固定 notebook 状态读取关键值。

允许排序、长宽表转换、单位换算和明确登记的展示变换；不得在绘图代码中重新定义指标、选择性过滤或重新运行统计检验。

### 3. 选择图形与面板

根据证据关系选择图形，不按个人偏好固定使用折线或柱状图。完整映射见 [实验图形类型映射.md](references/实验图形类型映射.md)。

主结果、消融、曲线、敏感性、分布、资源权衡、定性结果和失败案例应使用能直接支持其比较目的的形式。

### 4. 编写稳定代码

绘图代码放入：

```text
cvpr_workspace/analysis/figures/
```

采用固定代码和配置。命令只负责选择配置或输出位置，不能用大量 CLI 参数隐藏配色、筛选、指标或统计逻辑。

后续论文修改图形时复用同一脚本和源数据，通过版本化图形任务改变版式，不重新人工录入数字。

### 5. 导出

正式图形输出到：

```text
cvpr_workspace/result_package/figures/
```

根据使用场景提供适用的 SVG、PDF、PNG 或 TIFF，并保留绘图代码和图形源数据。格式要求由目标会议、期刊或用户决定，不硬编码单一模板。

### 6. 渲染核验

必须实际打开最终输出检查：

- 标签、图例、刻度和注释没有遮挡或裁切；
- 单位、方向、样本量和误差定义正确；
- 坐标范围和基线诚实；
- 颜色之外仍能区分关键系列；
- 面板编号和源数据对应；
- 图中数字与审核表格一致；
- 屏幕和适用打印尺寸下可读。

只检查绘图代码不能算完成。

### 7. 登记图形

以 [图形任务模板](assets/图形任务模板/figure.yaml) 保存图形契约，运行：

```bash
python3 <cvpr-figure-Skill目录>/scripts/validate_figure_manifest.py \
  <figure.yaml> --project-root <项目根目录>
```

## 与其他 Skill 的边界

- 数据完整性、聚合和统计：`cvpr-statistics`；
- DO Goal 判定：`cvpr-do`；
- 三审和用户路由：`cvpr-result`；
- 图形所表达的论文叙事与正文引用：后续论文 Skill；
- 方法架构图或纯概念插图：只有存在明确科研图形契约时才由本 Skill 处理，否则交给相应视觉能力。

## 硬性保护

- 不生成或补造实验数据；
- 不为了显著性过滤数据；
- 不修改指标和误差条含义；
- 不隐藏失败点或不利配置；
- 不使用误导性坐标轴、面积或颜色；
- 不把相关性图形写成因果结论；
- 不从图形视觉效果推导新的 Claim；
- 不只交付图片而缺少脚本和源数据；
- 不在未审核数据上生成正式论文图。

## 完成标准

- 图形目的、Claim、来源和比较关系明确；
- 使用已审核的结构化源数据；
- 绘图后端明确且唯一；
- 代码、配置、源数据和 Run 可追溯；
- 统计表达与 `cvpr-statistics` 一致；
- 至少保留一种可编辑产物；
- 所有正式导出均已实际渲染检查；
- 图形任务契约校验通过。
