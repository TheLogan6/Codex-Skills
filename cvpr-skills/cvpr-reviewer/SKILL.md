# CVPR Reviewer

## 定位

把本 Skill 作为通用 AI/ML/DL 投稿前科学审查能力。名称中的 CVPR 仅表示 `cvpr-skills` 品牌，不把标准写死为 CVPR；只有用户明确指定 venue 且提供可核验要求时才评估 `venue_fit`。

本 Skill 定义评审协议，强制调用 `cvpr-someagents` 模式 B 执行三位独立审稿。三位审稿人读取完全相同的冻结稿件和证据包，覆盖相同评审轴，只允许关注权重不同。不得虚构姓名、机构、资历、专业身份或编辑权限。

不修改稿件，不撰写作者回复，不改变 Goal、`cvpr-do` 判定或 `cvpr-result` 结论，不输出 accept/reject、录用概率或录用保证。

## 必读规范

- 冻结输入与派发审稿人前读取 [三位独立审稿协议.md](references/三位独立审稿协议.md)。
- 形成各审稿报告时读取 [通用AI论文评审轴.md](references/通用AI论文评审轴.md)。
- 汇总、保留少数意见和给出状态时读取 [审稿报告与综合契约.md](references/审稿报告与综合契约.md)。
- 实际多 Agent 编排必须读取并调用 `cvpr-someagents`，不能自行声称完成三审。

## 输入

- 已冻结的完整稿件、附录和补充材料；
- Claim、数字、引用、术语、表格和图形账本；
- `cvpr-result` 冻结结果及相关 Run、统计与复现材料；
- 最近一轮 `cvpr-paper-audit` 报告；
- 用户已明确指定时的 venue 名称及正式要求。

输入局部时可以执行有边界的科学审查，但必须标为 `partial`，每位审稿人都要说明不可评估项，且综合状态不能为 `reviewed`。

## 工作流

1. **冻结共同输入。** 创建唯一 `snapshot_id`，记录稿件、证据和审计报告的路径、摘要与 SHA-256。任何变化都需要新审稿轮次。
2. **确定评审范围。** 固定六个通用轴；仅在 venue 已确定并有要求证据时增加 `venue_fit`。不要临时添加未定义的评分轴。
3. **调用 `cvpr-someagents`。** 使用模式 B，同时派出恰好三位独立 Agent：
   - `contribution_and_positioning`：侧重贡献、新颖性、相关工作定位与影响边界；
   - `technical_validity`：侧重方法假设、推导、实现与技术正确性；
   - `experiments_reproducibility_and_communication`：侧重实验、公平性、统计、复现、清晰度、限制和伦理。
4. **保持独立。** 三位 Agent 接收同一快照、同一评审轴和同一输出契约；只增加各自的侧重点。在三份报告全部提交前互不查看输出。
5. **生成三份报告。** 每位审稿人都必须覆盖全部适用轴，给出证据位置、主要问题、次要问题、所需行动、不可评估项和科学状态。
6. **综合而非投票。** 协调者合并重复问题，建立每项问题与原报告的完整映射；所有只由一位审稿人提出的少数意见必须保留并说明。不能用二比一删除实质风险。
7. **给出边界状态。** 只允许 `reviewed`、`needs_revision` 或 `blocked` 等科学审查状态；不得冒充编辑决定。
8. **固化与校验。** 以 [科学审稿模板](assets/科学审稿模板/review.yaml) 保存，并运行：

```bash
python <cvpr-reviewer目录>/scripts/validate_scientific_review.py \
  <审稿文件> \
  --project-root <项目根目录>
```

## 三审通过边界

`reviewed` 只表示三份报告完整、没有未解决 blocker，且在当前冻结输入范围内没有必须先修复的 major 科学问题。它不表示录用、可投稿或 venue 接收概率。

只要存在开放 major/blocker、核心评审轴不可评估或完整稿件缺失，就使用 `needs_revision` 或 `blocked`。修复稿件后必须建立新快照重新审查。

## 明确禁止

- 不虚构三位审稿人的真实身份或专业履历；
- 不把侧重点包装成“统计学家”“领域主席”等身份；
- 不生成编辑决定信、accept/reject 或录用概率；
- 不自动修改正文、实验、图表或引用；
- 不撰写 rebuttal 或逐条作者回复；
- 不删除少数意见或无证据地调和分歧；
- 不用语言质量掩盖技术或实验问题；
- 不因目标 venue 未指定而自动套用 CVPR 标准。

## 完成标准

- 三位独立 Agent 确实由 `cvpr-someagents` 模式 B 派发；
- 三者输入快照完全一致且提交前互不可见；
- 三个侧重点各不相同，但每份报告覆盖全部适用轴；
- 所有问题都绑定稿件位置或证据引用；
- 综合报告可追溯到每份原始报告；
- 共识、分歧和少数意见均被保留；
- 没有编辑越权、录用保证、rebuttal 或自动改稿；
- 机器可读契约通过确定性校验。
