# 通用 AI 论文评审轴

## 固定评审轴

### `contribution_novelty`

- 核心贡献是否清晰、可证伪并有证据支持；
- 与近期相关工作的区别是否准确；
- 新颖性来自方法、理论、数据、系统或洞察中的哪一层；
- 是否把工程组合、规模效应或局部增益夸大为普遍创新。

### `technical_correctness`

- 假设、定义、推导、算法和代码实现是否相互一致；
- 方法机制是否由实验或分析支持；
- 边界条件、失败模式和适用范围是否明确；
- 理论性工作是否给出必要证明，实证工作是否避免因果越界。

### `experimental_rigor_fairness`

- 数据划分、训练预算、调参机会、预训练资源和评测协议是否公平；
- baseline 是否近期、相关并正确实现；
- 主实验、消融、稳健性、失败结果和不确定性是否足以支撑 Claim；
- 是否存在数据泄漏、测试集调参、选择性报告或不可比结果。

### `reproducibility`

- 代码、数据、环境、配置、种子、权重、入口和日志是否足够；
- 论文数字是否能回溯到冻结 Run 与统计产物；
- 第三方资源、许可证和不可公开限制是否透明；
- 复现声明是否与实际提供材料一致。

### `clarity`

- 问题、方法、贡献、实验和限制是否形成连贯论证；
- 术语、符号、公式、图表和章节引用是否清晰；
- 重要实现细节是否被藏在模糊表述中；
- 写作是否允许读者区分观察、推断和已证明结论。

### `limitations_ethics`

- 局限、负面结果、失效条件和外部有效性是否诚实；
- 数据来源、隐私、偏见、安全、滥用、能耗或社会影响是否按研究实际处理；
- 是否存在不适用于该研究却被模板化强加的伦理问题；
- 风险声明是否与实际应用和部署边界相称。

## 条件评审轴

### `venue_fit`

只有用户明确指定 venue 且提供官方要求证据时启用。检查论文类型、主题范围、篇幅、匿名、材料和可复现要求的匹配，不预测录用概率。

## 评估值

每个轴使用：

- `strong`：当前证据充分，未见重要缺口；
- `adequate`：基本成立，但仍有非阻断限制；
- `weak`：存在必须修复的主要问题；
- `not_assessable`：输入材料不足，不能判断。

评估值必须附理由和证据。不得用总分平均掉任一技术 blocker。
