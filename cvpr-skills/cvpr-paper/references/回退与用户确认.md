# 回退与用户确认

## 问题分层

| 问题 | 路由 |
|---|---|
| 章节结构、Claim 表达、缺少限制说明 | `cvpr-writing` |
| 引用缺失或支持不充分 | `cvpr-citation`，必要时先 `cvpr-academic-search` |
| 现有 Run 的数字或表格问题 | `cvpr-statistics` |
| 现有审核数据的图形问题 | `cvpr-figure` |
| 代码、数据、模型或许可证材料问题 | `cvpr-reproducibility` |
| 语言和术语问题 | `cvpr-polishing`，按需 `cvpr-humanizer` |
| 模板、编译、匿名或版面问题 | `cvpr-latex` |
| 现有 Plan 已覆盖但缺少新实验、新消融或新验证 | `cvpr-do → cvpr-result` |
| 现有 Plan 未覆盖必要实验阶段 | `cvpr-plan → cvpr-do → cvpr-result` |
| 评测协议、判据或代码库基础需改变 | `cvpr-goal` |
| 结果不再支持研究 IDEA | `cvpr-start` |

## 不能用文字解决的问题

如果核心 Claim 缺少实验支持，不能通过：

- 降低措辞后仍保留同一实质结论；
- 用相关文献代替本项目实验；
- 用定性案例代替约定的定量核验；
- 隐藏失败结果；
- 删除限制或不利比较。

## 用户确认

清晰自然语言请求已经授权相应原子执行，不为内部模式重复确认。

必须跳出讨论的事项：

- 论文核心论断或主线存在多个实质分支；
- 目标 venue/track 会改变模板、长度或内容；
- 需要新实验或改变协议；
- 需要公开、上传或披露代码、数据、模型；
- 要删除关键内容来满足篇幅；
- 完整初稿的提纲确认；
- 完整初稿的最终确认。

组合任务的调用顺序只需一句话说明。没有歧义的单项任务直接执行。
