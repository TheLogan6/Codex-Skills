# 论文路由契约

## 文件

```text
.cvpr/paper.yaml
.cvpr/paper/terminology.yaml
.cvpr/paper/numbers.yaml
.cvpr/paper/citations.yaml
```

模板位于：

```text
assets/论文状态模板/paper.yaml
assets/论文状态模板/terminology.yaml
assets/论文状态模板/numbers.yaml
assets/论文状态模板/citations.yaml
```

模板使用 JSON 表达；JSON 是 YAML 1.2 子集。

## paper.yaml 核心字段

- `paper_id`、`version`：稿件身份；
- `status`：总体状态；
- `active_result`：绑定的 Result、Goal 状态和 `snapshot_id`；
- `target`：venue、track、官方规则与模板；
- `ledgers`：Claim、术语、数字和引用账本；
- `manuscript`：稿件目录、当前版本、必需章节和渲染产物；
- `stage_statuses`：论文节点状态；
- `artifacts`：各原子 Skill 产物；
- `blockers`、`open_questions`；
- `user_confirmations`：两次完整初稿确认。

## 状态条件

### draft_ready

- `active_result.status = accepted`
- `active_result.route = paper`
- `active_result.goal_status = passed`
- 论证提纲确认已接受；
- 所有必需章节为 `accepted`；
- 证据、论证提纲、正文、引用、复现、润色和 LaTeX 节点均为 `accepted`；
- 当前产物中至少包含写作、引用、复现、润色和 LaTeX 产物；
- 当前稿件同时有源文件和成功渲染文件；
- 目标 venue、track、官方规则来源与模板已经核验；
- 没有 blocker；
- 当前正文及核心账本产物绑定活动快照。

### reviewed

在 `draft_ready` 基础上：

- `paper-audit` 节点为 `accepted`；
- `review` 节点为 `accepted`；
- `cvpr-paper-audit` 和 `cvpr-reviewer` 产物为 `current`；
- 不存在未解决 blocker。

### accepted

在 `reviewed` 基础上，最终初稿确认已接受。
