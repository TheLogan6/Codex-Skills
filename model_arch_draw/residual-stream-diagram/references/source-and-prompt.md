# Engram 与 mHC 样例

打开 [多路残差与 Single-Pass 参考图](engram-mhc.png)，对应用户技术报告第 9 节、DOCX 媒体 image9.png。分析以该文档为依据，原生成工具与提示词未知，以下结构不是对任意 mHC 版本的通用事实断言。

## 三个问题分三个区

**第一段：Engram 做了什么？** 输入是四条已存在的残差流，输出还是四条，`X̃=X+g v_E`。原图两个模块都使用 v；复用该方法时建议写 `v_E` 与 `v_F`，避免误以为查表 value 就是子层输出。

**第二段：mHC 如何处理这四条流？** 先 `u=A_prev X̃` 四合一，运行一次 `v_F=F(u)`，再 `Y=B X̃+C v_F` 写回四条。旁路画出 B 混合的是原来的四路状态。F 的盒子标 Attention 或 MoE，而不是同时计算两者。

**第三段：Single-Pass 改了什么？** 单独画 A 的传递：前一层 FFN 产生 A_prev，当前 Attention 消费 A_prev 并产生 A_attn，当前 FFN 消费 A_attn 并产生下一份 A。箭头仅表示系数传递。

原图把“先读状态生成 A，再次读取混合”与“已有 A_prev，读入即可混合”并排，解释的是数据依赖与访存机会，不是壁钟时间图。

## 维度与解释边界

```text
X, X̃, Y: [4,5120]
g: [4,1]; v_E: [1,5120]
A_prev: [1,4]; u, v_F: [1,5120]
B: [4,4]; C: [4,1]
A_prev X̃: [1,5120]
B X̃ + C v_F: [4,5120]
```

材料正文将传统形式写为 `Y=BX+CF(AX)`，Single-Pass 形式用前一子块的 A 替换当前 A。B/C 仍从当前状态预测。若新任务要求完整实现，需补系数预测、约束、归一化与初始边界；本示例重点是数据流与系数时序。

报告第 9 节的 `20d→10d` 是特定残差处理链在 n=4 时的访存计数；不能标成整模型速度翻倍。Engram 只插入指定层，图中的串接关系不表示每一层都有 Engram。

## 迁移检查

当新材料规定 n=8、d=4096、A 由当前 X 预测，应画 `[8,4096]→[1,4096]→[8,4096]`，并保留当前状态到 A 的依赖，不能继承 Single-Pass 的 A_prev 或“减少一半读取”的结论。若没有注入模块，只画后两部分中需要的内容。
