# 架构样例与提示词

本技能来自用户提供的《DeepSeek-V4.1-Flash 技术报告｜CED、CSA2、Engram 与 KV Cache》。这是本地材料的作图方法提炼，不是对模型最新事实的独立审计。本文档标明资料基线为 2026-09-10。

打开 [模块地图参考图](module-map.jpeg)。它位于报告第 1 节；原 DOCX 媒体项为 image1.jpeg。其生成工具和原提示词未知。第 2.1 节另有标注为官方 Figure 3 的层栈图，不能把它也归因为本次 AI 自绘。

## 真正可迁移的设计

1. 左侧把图像编码、降采样、投影、embedding 展开，主干边界单独框住。因此 32 层 ViT、2 层 MLP 和 40 层语言主干不会混计。
2. Encoder 内部按 L1–2、L3–8、L9–14、L15–20 分组；Decoder 按 L21–24 和后续重复组分组。层号比画 40 个相同盒子更易查阅。
3. H20 是关键交接点，既进入 Decoder，也生成供 Decoder 读取的全局 KV。状态节点离主路径较近，数据来源无需从长段文字推断。
4. Engram 与 DSpark 在主干外标注角色；底部有公共层属性与数量核对。这些摘要承接主图，不代替实际接入关系。

## 应保留的准确性边界

- `2 + 3×6 + 4 + 4×4 = 40`；ViT 和 DSpark 不计入主干。
- 本材料中全局缓存源为 L3、L9、L15、L21；组数与每层仍进行的 Attention 运算是两种计数。
- 原图的 N/2 是偶数长度的简化；精确条目数要考虑 floor 和未配对尾部。
- 原图 DSpark 只有候选验证方向的概览，新图若展开 DSpark，应补实际输入特征来源，不能仅凭该总览猜测。
- 不将这些层号、维度、配色变成新模型的固定模板数据。

## 迁移检查

若新材料是“12 层纯文本 decoder、每层 GQA、无草稿网络”，应得到 12 层 decoder 总览，不能继承因果 Encoder、四组共享缓存、Engram 或视觉前端。若所有层相同，用一个 block ×12 即可。
